# Marketing Skills — обзор библиотеки и наша стратегия обучения

**Основа:** [Marketing Skills for AI Agents](https://github.com/coreyhaines31/marketingskills) — открытая библиотека инструкций для маркетинговых задач (по состоянию на 21 октября 2026 года).

## Что это

`Skill` — набор инструкций для AI-агента, обычно оформленный файлом `SKILL.md`. Он задаёт область применения, порядок работы, данные для анализа и ограничения. Сам по себе Skill не даёт доступа к CRM, сайту или рекламному кабинету. Доступ осуществляется через отдельные инструменты и разрешения.

Библиотека полезна для маркетинговых задач: SEO и AI SEO, Google/Meta Ads, CRO, атрибуция и аналитика, копирайтинг, исследования аудитории, удержание клиентов, RevOps, автоматизация.

## Как навыки взаимодействуют

По инструкциям проекта прежде всего важен `product-marketing`: он задаёт общий контекст продукта, покупателя, целей и позиционирования. Другие навыки используют этот контекст. Обычная последовательность: контекст бизнеса → тематический Skill → проверка исходных данных → анализ → рекомендации → тест/внедрение по согласованию.

## Применение в нашем обучении

Будем изучать оригинальные Skills по одному и проверять на реальных задачах продаж твёрдого топлива в Праге и Киевском регионе. Факты и фактические результаты отделяем от гипотез; имеющиеся данные не подменяем вымышленными показателями.

### Важные направления

| Раздел | Для чего |
|---|---|
| `product-marketing` | Контекст бизнеса, аудитория, предложение, конкуренты |
| `seo-audit`, `ai-seo` | Технический аудит и видимость в AI-ответах |
| `ads`, `ad-creative` | Работа с Google/Meta Ads и креативами |
| `analytics`, `attribution`, `conversion-tracking` | События, UTM, звонки, связь каналов с продажами |
| `cro` | Повышение конверсии сайта и форм |
| `revops` | Связь маркетинга и CRM, процессы обработки лидов |
| `marketing-loops` | Повторяемые маркетинговые процессы |

## Практический пример

Задача: «Реклама приводит заявки, но неясно, сколько покупателей она дала». Сначала определяем, что считается конверсией, затем проверяем качество событий (`analytics`), атрибуцию источников (`attribution`), показатели рекламы (`ads`) и этапы работы с лидами (`revops`). Не считать цифры рекламной платформы подтверждёнными продажами без сопоставления с CRM.

## Безопасное использование

- В публичный Fork не добавлять телефоны клиентов, записи разговоров, токены, приватные отчёты и чувствительные финансовые данные.
- Сначала read-only подключение к CRM/рекламе, затем только согласованные изменения.
- Сохранение этих файлов в GitHub **не устанавливает** навыки в ChatGPT, Claude или Codex; подключение агента настраивается отдельно.
