# Практика 1. Что считать главной конверсией

**Цель:** определить, какое действие будем считать результатом маркетинга, прежде чем изучать рекламу, SEO и аналитику.

## Возможные результаты (разные стадии)

- **Лид:** входящий звонок или форма заявки. Это не обязательно покупатель.
- **Заказ:** созданная в KeyCRM запись о намерении купить. Ещё не гарантирует завершённую продажу.
- **Продажа:** выполненный заказ по определённому правилу признания выручки.
- **Повторная продажа:** завершённая покупка существующего клиента.

## Заполнить при обучении

| Вопрос | Ответ |
|---|---|
| Рынок | Прага / Киевская область / оба, но отдельно |
| Главная конверсия для бизнес-отчёта | Не выбрана |
| Промежуточная конверсия для рекламной оптимизации | Не выбрана |
| Как определяем нового клиента | Не решено |
| Как определяем повторную покупку | Не решено |
| Откуда берём правду о продажах | Требует подтверждения |
| Какие события и UTM уже сохраняем | Проверить |
| Какие пробелы есть между рекламой и CRM | Проверить |

## Правило для будущего AI-анализа

В любом отчёте отделять количество лидов, количество заказов и количество завершённых покупок. CPA за лид не называть стоимостью покупателя; платформенную атрибуцию не приравнивать автоматически к доказанной причинности.
