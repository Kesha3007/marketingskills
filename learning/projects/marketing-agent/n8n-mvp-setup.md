# Как создать первого агента в n8n — учебная версия

Нужен доступ к действующему n8n (Cloud или self-hosted) и к OpenAI API с отдельным биллингом. **API-ключи в GitHub и чат не публиковать.**

## Самый простой сценарий без CRM

1. Открой n8n и создай новый workflow.
2. Выбери Chat Trigger (например, «When chat message received») или доступный конструктор агентов в твоей версии n8n. Интерфейс отличается по версиям.
3. Добавь **AI Agent**; подключи совместимую ноду OpenAI Chat Model и выбранную модель.
4. В credentials n8n авторизуй OpenAI API (секрет остаётся в n8n, не в публичном repo).
5. В system instructions вставь текст из `agent-instructions-v0.md`; добавь небольшой проверенный контекст продукта.
6. Не подключай инструменты записи в CRM или изменения рекламных кампаний. Memory необязательна для первых тестов.
7. Нажми тестовый запуск; задай вопросы из `test-cases.md`; проверь, что агент не выдумывает текущие данные.
8. Только после успешного теста подключи один read-only источник (агрегированные данные) и проверяй каждое добавление отдельно.

## Для n8n Agent Builder
Если в твоей версии есть отдельный Agent Builder, можно создать Agent напрямую: модель → инструкции → инструменты → тест → публикация. В некоторых версиях и планах функция может отличаться; справка n8n: https://docs.n8n.io/build/build-and-manage-agents/.

## Дальнейший шаг: связать с маркетингом и CRM
Для запроса «какие кампании дали реальные продажи?» потребуется:
- прочитать агрегированные расходы и результаты из Google/Meta;
- прочитать нужные статусы/суммы из KeyCRM;
- согласовать определения «первая/повторная/завершённая продажа»;
- совместить по доступным идентификаторам/UTM и показать неполноту атрибуции.

Это отдельный проект интеграций; наличие навыка `ads` и системного промпта **не подключает** API.

## Об инфраструктуре
- n8n Cloud: сервер для оркестратора организует провайдер;
- существующий защищённый n8n на VPS: обычно достаточно для начального решения;
- если хочется полностью собственную программу: OpenAI Agents SDK + Python/TypeScript с отдельным исполнением приложения.

**После выполнения шагов 1–7:** можно считать агента v0 запущенным (умеет отвечать по инструкции), но не подключённым к данным компании.
