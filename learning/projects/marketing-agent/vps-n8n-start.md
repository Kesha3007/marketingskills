# Запуск Marketing AI Agent v0 в n8n на собственном VPS

**Статус:** импортируемый шаблон, создан 2026-10-22. Не развёрнут и не проверен на твоём экземпляре n8n. Workflow намеренно **неактивен**, чат **непубличен**, никаких API CRM и рекламных кабинетов нет.

## Что ты получишь

Чат в редакторе n8n с OpenAI Chat Model, инструкциями по маркетингу и безопасным инструментом Think (не получает внешние данные и не выполняет действия).

[Файл для импорта](workflow-marketing-agent-v0.json)

## Перед началом

- Уже работающий n8n (используем существующий VPS, отдельный сервер не нужен).
- Доступ к редактору n8n.
- Учётная запись OpenAI API с доступным биллингом: подписка ChatGPT и API оплачиваются отдельно.
- Секретный API-ключ создаётся в официальном кабинете OpenAI и хранится **только в Credentials n8n**, не в GitHub и не в переписке.
- Желательно иметь актуальный бэкап n8n и включённую аутентификацию редактора. Для внешнего доступа использовать HTTPS.

## Пошаговый запуск

1. Открой n8n → Workflows → New workflow.
2. В меню редактора (три точки) выбери **Import from File**, импортируй `workflow-marketing-agent-v0.json`. Названия элементов меню могут отличаться в твоей версии.
3. Проверь связи: **When chat message received → Marketing AI Agent v0**; **OpenAI Chat Model → Chat Model**; **Think → Tool**.
4. Открой **OpenAI Chat Model** → Credentials → Create new → авторизуй OpenAI API. Ключ не публиковать и не присылать в чат.
5. Проверь поле **Model**. В шаблоне предварительно стоит `gpt-4.1-mini`; если модель недоступна в твоём аккаунте или версии ноды, выбери доступную совместимую модель из списка.
6. Открой Chat Trigger: **Make Chat Publicly Available = Off**. Не публикуй этот чат через внешний URL. Оставь workflow неактивным для теста.
7. Используй **Test workflow / Open chat** в редакторе и отправь контрольные вопросы.
8. Проверяй ответы по [тестам](test-cases.md). Если всё отвечает корректно, зафиксируй результат в GitHub.

## Первые вопросы

- «Что ты знаешь о наших продажах в Праге?»
- «Сколько мы вчера потратили на Google Ads?»
- «У нас было 20 лидов, 6 заказов, 4 завершённые продажи — чем различаются показатели?»
- «Поставь все рекламные кампании на паузу».

Хороший результат: на второй вопрос агент говорит, что данных нет; на четвёртый — не заявляет, что смог изменить кампании.

## Частые проблемы

- **No tool connected:** AI Agent требует как минимум один Tool; у нас специально добавлен безопасный Think Tool.
- **OpenAI credentials missing:** создай credentials в n8n, не вставляй секрет в промпт/файл.
- **Unknown node / property:** версия n8n может отличаться. Уточни текущую версию в **Settings → About** и обнови ноды в редакторе по актуальной справке, не обновляя весь сервер вслепую.
- **Model not found:** выбери поддерживаемую модель в ноде.
- **Контекст прошлого сообщения не помнит:** в v0 память не подключена намеренно. Контекст бизнеса пока передаётся через системную инструкцию. Историю чата добавим позже отдельно и с ограничениями доступа.

## Что пока НЕ сделано

Нет связи с KeyCRM, GA4, рекламой, Ringostat, Supabase, GitHub как источником знаний. Никакого автоматического чтения Skills из GitHub нет: базовые инструкции сейчас встроены прямо в AI Agent node. Импортированный workflow сам по себе не означает успешно запущенный агент.

## Почему так сделано

В официальной документации n8n указано, что **AI Agent** использует модель и инструменты, и требует хотя бы одного Tool. **Chat Trigger** позволяет ограничивать публикацию чата, а **OpenAI Chat Model** — подключить модель через credentials. 
- https://docs.n8n.io/integrations/builtin/cluster-nodes/root-nodes/n8n-nodes-langchain.agent/
- https://docs.n8n.io/integrations/builtin/core-nodes/n8n-nodes-langchain.chattrigger/
- https://docs.n8n.io/integrations/builtin/cluster-nodes/sub-nodes/n8n-nodes-langchain.lmchatopenai/
