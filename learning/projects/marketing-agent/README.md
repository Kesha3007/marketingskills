# Business & Marketing AI Agent — наш проект

**Статус:** архитектура и первый набор инструкций сохранены; к рабочему n8n и API ещё НЕ подключены.
**Дата старта:** 2026-10-22.
**Цель:** создать собственного агента для маркетинга, аналитики и операционных задач, адаптированного под два отдельных рынка (Прага и Киевская область), без смешения данных.

## Что будет в финале
- Отвечает на вопросы о маркетинге и бизнесе с опорой на проверенный контекст.
- Сверяет рекламные показатели с фактическими заказами/завершёнными продажами.
- Указывает на ошибки трекинга, просадки воронки, возможности SEO и рекламы.
- Готовит задачи и изменения **как черновики**; выполняет разрешённые действия только после проверки человеком.
- По мере развития работает с KeyCRM, GA4, рекламой, n8n, Supabase; к этим системам доступ пока не настроен.

## Порядок создания
1. Уточнить бизнес-контекст (урок 2, `product-marketing`).
2. Запустить агента v0 в n8n: чат + OpenAI-модель + инструкция, пока **без доступа к CRM**.
3. Добавить один инструмент **только для чтения**: отчёт/демо-данные без персональных сведений; проверить ответы.
4. Настроить read-only получение реальных агрегированных показателей, определения продаж и источников.
5. Подключать другие источники по одному, тестируя права и корректность.
6. Создавать задачи и вносить изменения только по явно подтверждённым правилам с журналом и откатом.
