# Урок 1. Что такое AI Skill и как он работает

**Источник:** https://github.com/coreyhaines31/marketingskills

## 1. Skill — инструкция, не программа
`SKILL.md` — Markdown-документ с правилами выполнения определённого класса задач. Он не подключается к рекламному кабинету сам по себе.

## 2. Как читать структуру
- `name` — машинно читаемое имя навыка.
- `description` — когда агенту стоит обращаться к этому навыку.
- Заголовки Markdown — шаги, вопросы, ограничения, формат результата.
- `references/` — дополнительные методики и подробные материалы.
- `.agents/product-marketing.md` — общий контекст бизнеса, на который ссылаются навыки.

## 3. Разница между понятиями
- **Skill:** как выполнять задачу.
- **Агент:** кто выполняет задачу и управляет шагами.
- **Инструмент/API:** через что агент получает данные и совершает разрешённые действия.
- **Автоматизация:** когда и при каком событии запускается последовательность действий.
- **GitHub:** где хранятся и версионируются файлы; загрузка в GitHub сама по себе не активирует Skill в ChatGPT.

## 4. Пример
Запрос: «Почему из рекламы пришло много заявок, но мало продаж?»

1. `product-marketing` — понимание товара, аудитории и цели.
2. `ads` — оценка рекламы и качества лидов.
3. `analytics` — события и корректность измерений.
4. `attribution` — связь рекламы с заказами и выручкой, без претензии на абсолютную причинность.
5. `revops` — этапы обработки заявок в CRM.

Результат должен включать проверенные факты, гипотезы и данные, которых не хватает.

## 5. Упражнение
Для одного рынка (например, продажи твёрдого топлива в Праге) определите:
1. Главное действие, которое считается успехом: заказ, оплаченная покупка или другое.
2. Какие данные уже есть: рекламный кабинет, сайт, CRM, коллтрекинг.
3. Какой показатель вызывает сомнение: стоимость заявки, стоимость покупателя, повторная покупка или атрибуция.

Затем выберите соответствующие навыки и опишите последовательность проверки. Не меняйте рекламные настройки без анализа.
