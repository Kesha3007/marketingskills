# Как работать с личным Fork

**Оригинал:** https://github.com/coreyhaines31/marketingskills  
**Наш Fork:** https://github.com/Kesha3007/marketingskills

## Что означает Fork

Fork — отдельная копия репозитория в твоём аккаунте, сохраняющая связь с оригиналом. В неё можно добавлять собственные документы и модифицировать инструкции. Изменения в Fork не меняют репозиторий автора.

## Где лежат наши материалы

- `learning/README.md` — оглавление;
- `learning/overview.md` — обзор;
- `learning/plan.md` — программа;
- `learning/lessons/` — уроки;
- `learning/exercises/` — задания;
- `learning/projects/` — будущие проекты;
- `.agents/product-marketing.md` — учебный черновик контекста бизнеса.

## Как пользоваться

1. Открой `learning/README.md` в своём Fork.
2. Для каждого урока изучай оригинальный `skills/<name>/SKILL.md`, затем наши заметки.
3. После практики сохраняй выводы в папку `learning/`.
4. Если автор обновил свою библиотеку, на GitHub можно синхронизировать Fork с оригиналом (Sync fork), предварительно проверить конфликтующие изменения.
5. **Не заменяй** оригинальный README и папку `skills/` нашим учебным комплектом.

**Важно:** Сохранение файлов в GitHub не устанавливает навыки в ChatGPT, Claude или Codex. Для фактического применения их нужно подключить к поддерживаемому агенту.

Не добавляй в публичный репозиторий API-ключи, клиентские контакты, записи разговоров и приватную аналитику.
